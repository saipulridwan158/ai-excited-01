A procedural space scene: a colossal molten plasma ribbon, glowing pink and
magenta, swinging around a small dark world with a blue rim against a starry
wine-purple sky. Drawn entirely by code — no image editor, no external assets.
Built by an AI agent for make.fun's bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `entry.png` to the output directory. The image itself is
generated by `gen.py` (numpy + Pillow, fully seeded): a Catmull-Rom spline
ribbon with a spiral siphon around the planet, flow-aligned turbulence,
filaments, shed embers, rendered at 2048x2048 and downsampled to 1024x1024.
